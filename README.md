# SAP TechEd 2026 [Berlin]

## Introduction 

In this repository, you will find the presentation from the SAP TechEd 2026 Community Track. The session, "Fiori elements for ABAP developers", focused on how ABAP developers can get started in the world of Fiori, covering what to learn, what is important, and the skills required for the full-stack developer of tomorrow.
